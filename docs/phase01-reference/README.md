# BRONEE HRMS

Workforce Management Platform for **BRONEE Limited**.

## Live

https://bronee-hrms.pages.dev

## Cloudflare Pages settings (required)

| Setting | Value |
|---------|--------|
| Framework preset | Vite |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Root directory | `/` |

## Phase 01 included

- Employee Login (spec copy + validation messages)
- Signup with departments / Sales sub-departments + OTP step UI
- Forgot password page
- Employee shell (desktop sidebar + mobile bottom nav)
- Dashboard layout (attendance controls placeholder)

Auth API, D1, attendance engine: later phases.
